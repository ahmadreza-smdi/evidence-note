EVIDENCE NOTE — AHMADREZA SAMADI

A new offline claim/source note editor for AI for property decisions.
This is a working editor and export/restore tool, not another blank worksheet,
quiz, calculator, model benchmark, appraisal or automatic fact checker.

Open index.html in a browser. It needs no installation, server or account.
Record one claim, its source and dates, missing evidence and the next check.
The preview preserves blanks as "Not recorded". Source relationships are always
labelled as your recorded judgement, never as a conclusion made by the tool.
The checks cover recording gaps and malformed fields, not evidence adequacy.

Try the fictional example: all property names, records and dates are invented.
Nothing is fetched from the source URL. All preview fields are literal text.
No analytics, storage, automatic network requests or personal data collection.
There are only explicit links to the author's existing public pages.

Save JSON to retain your note; Open saved JSON restores it locally. Invalid
imports keep the current note intact. Download Markdown for a text handoff, or
readable standalone HTML for a document that opens/prints without the editor.
Print note uses your own browser's print dialog. Reloading clears unsaved fields.
Clear note asks once so an accidental click does not discard your draft.

Developer source: template.html, app.js, core.js and example.json.
Run Python 3 build.py to rebuild the self-contained HTML and ZIP. All font and
monogram bytes are local. Run node test_core.cjs for the pure core checks.
No dependencies or package installation is required.
